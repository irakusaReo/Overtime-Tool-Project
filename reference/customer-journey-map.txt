3. End-to-End Customer Journey

Stage 1: Overtime Requirement Created

Workforce Actions

-   Workforce Analysts logs in

-   Creates overtime campaign (advertisements)

-   Sets:

    -   Date

    -   Start Time

    -   End Time

    -   Queue/Skill

    -   System computes Duration (End Time – Start Time)

    -   Workforce inputs slots available.

    -   Number of agents for each slot.

    -   System converts agents to hours (Hours = Number of Agents x Duration).

    -   Select Eligibility Rules to Apply (Flexible rule: Absent Previous Week or Two Week).

    -   Fixed rules: Fixed Rules: 11 hours, Annual Leave and 6-days rule. (Refer to CALL CENTER OVERTIME APPROVAL GUIDE).

    -   Publish slots.

-   Workforce Management creates an overtime advertisement using the following information:

  ----------------------------------------------------------------------------------------------------------------
  Field                            Description                                             Required
  -------------------------------- ------------------------------------------------------- -----------------------
  Skill                            Skill required for the overtime shift.                  Yes

  Required Date                    Date on which overtime is required.                     Yes

  Start Time                       Overtime Start time.                                    Yes

  End Time                         Overtime end time.                                      Yes

  CEEs/Support Analysts Required   Number of CEEs/Support Analysts required.               Yes

  Published                        Controls visibility to applicants.                      Yes

  Status                           Current advertisement lifecycle status.                 Yes

  Created By                       Workforce analyst/user who created the advertisement.   Yes
  ----------------------------------------------------------------------------------------------------------------

System Actions

-   Publishes overtime opportunity

-   Determines eligible CEE/Support Analysts automatically (as per the CALL CENTER OVERTIME APPROVAL GUIDE)

Opportunities

Appendix 1: User Stories

CEE User Stories

US-01: Profile Auto-population & Apply on Behalf Feature

-   User Story: As a CEE, I want the dashboard to auto-populate my profile details and allow me to apply for Overtime (OT) on behalf of someone else, so that I can save time and assist my team members when needed.

-   Acceptance Criteria:

    -   AC1: When logged into the system, the dashboard must automatically display the logged-in CEE's profile and name without requiring manual data entry.

    -   AC2: The system must provide a clear option (e.g., checkbox or toggle) to "Apply on behalf of another person."

    -   AC3: Selecting this option must present a searchable field to select a different agent by name or employee ID.

US-02: Skillset Visibility

-   User Story: As a CEE, I want to view the specific skillsets that an agent can handle, so that OT requests can be aligned accurately with correct tasks.

-   Acceptance Criteria:

    -   AC1: The dashboard must display a visible list of skillsets/competencies associated with the selected agent's profile.

US-03: Restricted OT Hour Visibility

-   User Story: As a CEE, I want the system to restrict the visible precheck options to only the hours where OT is actively available, so that I do not waste time applying for invalid slots.

-   Acceptance Criteria:

    -   AC1: The OT qualification precheck must automatically filter out unavailable hours.

    -   AC2: Users must only be able to see and select from hours designated as "Active OT Slots."

US-04: Automated Backend OT Rule Checks

-   User Story: As a CEE / System, I want the backend to automatically validate requests against predefined OT rules (6-day rule, sick off status, 11-hour rest rule), so that compliance issues are caught automatically before submission.

-   Acceptance Criteria:

    -   AC1: System must reject requests if the agent has worked 6 consecutive days.

    -   AC2: System must block applications if the agent is marked as "Sick Off."

    -   AC3: System must enforce an 11-hour rest window between shifts before approving an OT slot.

US-05: Monthly/Weekly Hour Automation Caps

-   User Story: As a CEE, I want an option to set automated caps on hours worked (e.g., maximum 10 weekday hours and 8 weekend hours), so that I can manage my scheduled availability without manual tracking.

-   Acceptance Criteria:

    -   AC1: Provide configuration inputs where a user can define their target/maximum hours split by weekday and weekend limits.

WORKFORCE User Stories

US-06: Workforce Qualification Prechecks

-   User Story: As a Workforce Analyst, I want the system to automatically block unqualified agents or those who fail to meet shift thresholds from applying, so that unusable applications are filtered out instantly.

-   Acceptance Criteria:

    -   AC1: The system must run a qualification check at the moment of submission and display a hard stop error message if requirements aren't met.

US-07: Automated SMS & Email Notifications

-   User Story: As a Workforce Analyst, I want the system to send automated email and SMS notifications when OT is approved, so that agents are updated immediately without manual outreach.

-   Acceptance Criteria:

    -   AC1: Trigger a confirmation email and SMS instantly upon status change to "Approved."

    -   AC2: Notifications must include key details: Date, Approved Hours, and Slot Time.

US-08: Max Application Threshold Per Slot

-   User Story: As a Workforce Analyst, I want to set a maximum threshold of applications allowed for any given OT slot, so that slots do not become over-allocated.

-   Acceptance Criteria:

    -   AC1: Admins must be able to define a maximum application cap per slot.

    -   AC2: The slot must change status to "Closed" or "Full" once the cap is met.

US-09: Bulk Approval Functionality

-   User Story: As a Workforce Analyst, I want to bulk approve required application batches at once (e.g., approving 20 applications concurrently), so that I can minimize handle time and operational overhead.

-   Acceptance Criteria:

    -   AC1: The analyst must be able to select multiple agent rows using checkboxes and click a single "Bulk Approve" button.

US-10: Accurate Data Export Formatting

-   User Story: As a Workforce Analyst, I want the system to capture and retain the exact, correct agent details during data exports, so that there are no payload discrepancies in external reporting tools.

-   Acceptance Criteria:

    -   AC1: Exported files (.CSV/.XLSX) must cleanly capture all required fields (Agent ID, Name, Department, Approved Hours) without formatting errors.

US-11: Auto-Cancellation for Inactive Agents

-   User Story: As a Workforce Analyst, I want the system to automatically cancel an approved OT slot if the agent fails to log in, so that unfulfilled slots can be recycled or released back into the pool.

-   Acceptance Criteria:

    -   AC1: The backend must monitor active agent statuses against scheduled OT start times.

    -   AC2: If an agent is not logged in within a configurable grace period after the OT start time, status must auto-update to "Cancelled - No Show."

Appendix 2: CALL CENTER OVERTIME APPROVAL GUIDELINES

1.  OT approvals will be done on first come first served basis.

2.  Overtime will be awarded on need basis after advertisement has been sent out.

3.  Ensure you have the required Skill to support the queue whose overtime you are applying for.

4.  Overtime will not be granted if the advertised slots are full.

5.  When applying for Overtime on your off day, apply for a full day or split shift (6/7/5/4/3hours) depending on the advertised hours. Less than 3hrs will not be updated.

6.  You must remain with at least one-off day in a week when applying for Overtime.

7.  When on a scheduled 8hr shift you can apply for a maximum of 2hrs overtime Extension.

8.  If you are granted full-shift overtime, a further two-hour overtime extension cannot be provided.

9.  When affected by power/system outage or any other outage that may lead to you not completing the updated Overtime. Kindly raise a ticket for it to be cancelled and apply again when stable to do the Overtime.

10. Do not apply for Overtime while on leave.

11. Ensure you observe at least 11hours break to the next shift login when applying for Overtime(11-hour rule).

12. Ensure you do not work for more than 6 consecutive days. Observe the rule for enough rest!

13. When doing Overtime for another queue, ask for skill set changes via helpdesk 5 minutes to the start of the Overtime. Late requests or no requests at all will lead to Overtime cancellation.

14. Overtime approval for the next day are done and updated the previous day between 11am-8pm. Apply early to allow for on time approval.

15. For agents on WFO, You May apply for overtime as long as it does not interfere with your regular office schedule. Ensure you Work from the office on days scheduled to WFO.

16. When doing overtime, ensure you don’t surpass the 72hrs overtime Limit in a month.

17. Staff who have been redeployed to other queues because of ENT issues will not be allowed to do Voice overtime.

18. Staff on mother’s shift, or unique short/special shifts that are less than 40hrs in a week are not eligible to do overtime

19. Staff with special shift requests for off days will not be eligible for overtime on those off days.

20. Staff on bundle shifts prescribed by the CHA will not be eligible for overtime during bundle breaks.
